# Dataset

This project uses a consolidated ovarian cancer clinical dataset along with derived sub-datasets created for specific analytical questions.

## Main Dataset

The main dataset was used for data preprocessing, feature engineering, exploratory analysis, and derivation of the analytical subsets used throughout the project.

The dataset is externally hosted and is therefore not redistributed in this repository.
